# Clara Fonts

Web fonts used by Clara, OK's design system. All files are `.woff2`.

## Font rules — never break these

- **OK family** — used for H1 and H2 only.
- **Fellix** — used for H3, H4, body, links, labels and buttons.
- Never substitute any other font.
- Never write in ALL CAPS.

See [`../CLARA.md`](../CLARA.md) for the canonical `@font-face` declarations and full typography spec.
