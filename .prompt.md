# Before generating any prototype

**DO NOT START CODING until you have done these steps:**

## 1. Understand the token system

Clara has **two token layers**:

| Layer | Name | Usage | Example |
|---|---|---|---|
| Base values | **Primitives** | NEVER use | `var(--color-red-800)` — forbidden |
| Semantic names | **Semantic** | ALWAYS use | `var(--color-actions-button-primary-background)` — required |

**Why?** If OK's brand changes from red to another color, only ONE semantic token needs updating. The entire system updates instantly.

## 2. Check the token mapping

Before writing any CSS, look up which semantic token to use:

| Purpose | Semantic Token | Example usage |
|---|---|---|
| Button background (primary) | `var(--color-actions-button-primary-background)` | Primary button bg |
| Button text (primary) | `var(--color-actions-button-primary-text)` | Primary button text |
| Button background (secondary) | `var(--color-actions-button-secondary-background)` | Secondary button bg |
| Body text | `var(--color-content-default)` | Paragraphs, labels |
| Subtle text | `var(--color-content-subtle)` | Helper text, captions |
| Links | `var(--color-actions-link-default)` | Link text |
| Borders | `var(--color-border-bold)` or `var(--color-border-subtle)` | Input borders, dividers |
| Input background | `var(--color-forms-input-background-default)` | Input field bg |
| Input border | `var(--color-forms-input-border-default)` or `hover` or `focus` | Input field border |
| Success | `var(--color-feedback-success-bold)` or `subtle` | Success messages |
| Error | `var(--color-feedback-error-bold)` or `subtle` | Error messages |
| Warning | `var(--color-feedback-warning-bold)` or `subtle` | Warning messages |

## 3. Copy component CSS from CLARA.md exactly

When using a Clara component (Button, Input, Checkbox, etc.), copy the HTML and CSS **character for character** from CLARA.md. Do not modify or "improve" it.

## 4. Before finishing

Scan your CSS and ask yourself:

- [ ] Is there ANY hardcoded color? (e.g., `#460019`, `#FF3C3C`, `rgb(70, 0, 25)`)
  - If YES → delete it and use a semantic token instead
  
- [ ] Is there ANY primitive token? (e.g., `var(--color-red-800)`, `var(--space-md)`)
  - If YES → replace with the correct semantic token
  
- [ ] Are ALL colors from the semantic palette?
  - If NO → fix before submitting

**If you fail any check, rewrite your CSS completely before submitting.**

## Example: The right way

❌ WRONG:
```css
.card {
  background: #460019;  /* Hardcoded color — forbidden */
  color: var(--color-red-800);  /* Primitive token — forbidden */
  border: 2px solid var(--color-border-subtle);  /* Correct */
}
```

✅ RIGHT:
```css
.card {
  background: var(--color-backgrounds-elevated);  /* Semantic token */
  color: var(--color-content-default);  /* Semantic token */
  border: 2px solid var(--color-border-subtle);  /* Semantic token */
}
```
