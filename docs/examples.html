Clara Design System

Component examples with copy-paste ready HTML snippets

These are live examples of all Clara components. Click any code snippet to copy it to your clipboard.

💡 Pro tip: All components use semantic tokens. Never use primitive tokens (--color-red-800) or hardcoded colors (#460019) in your code.

Button

Use buttons for primary and secondary actions. Primary for the most important action on a page.

Primary buttons

Small
HTML
<button class="clara-button clara-button--primary clara-button--small">Click me</button>
Large
HTML
<button class="clara-button clara-button--primary clara-button--large">Click me</button>
Disabled
HTML
<button class="clara-button clara-button--primary clara-button--small" disabled>Click me</button>

Secondary buttons

Small
HTML
<button class="clara-button clara-button--secondary clara-button--small">Click me</button>
Large
HTML
<button class="clara-button clara-button--secondary clara-button--large">Click me</button>
Disabled
HTML
<button class="clara-button clara-button--secondary clara-button--small" disabled>Click me</button>

Input

Text input fields with optional labels and helper text. Always include a label — never use placeholder as a substitute.

States

Default
Enter your email address
HTML
<div class="clara-input"> <label class="clara-input__label">Email</label> <input class="clara-input__field" type="text"> <span class="clara-input__helper">Enter your email address</span> </div>
Error
Invalid email format
HTML
<div class="clara-input clara-input--error"> <label class="clara-input__label">Email</label> <input class="clara-input__field" type="text"> <span class="clara-input__helper">Invalid email format</span> </div>
Disabled
This field is disabled
HTML
<div class="clara-input clara-input--disabled"> <label class="clara-input__label">Email</label> <input class="clara-input__field" type="text" disabled> <span class="clara-input__helper">This field is disabled</span> </div>

Checkbox

Checkbox inputs with inline labels. Always include a label. Touch target is 12px padding around the checkbox.

States

Unchecked
HTML
<label class="clara-checkbox"> <input type="checkbox" class="clara-checkbox__input"> <span class="clara-checkbox__label">I agree to the terms</span> </label>
Checked
HTML
<label class="clara-checkbox"> <input type="checkbox" class="clara-checkbox__input" checked> <span class="clara-checkbox__label">I agree to the terms</span> </label>
Disabled
HTML
<label class="clara-checkbox clara-checkbox--disabled"> <input type="checkbox" class="clara-checkbox__input" disabled> <span class="clara-checkbox__label">I agree to the terms</span> </label>

Radio Button

Radio buttons for mutually exclusive choices. Always use radio buttons in a group with a shared name attribute.

States

Unselected


HTML
<label class="clara-radio"> <input type="radio" class="clara-radio__input" name="group"> <span class="clara-radio__label">Option A</span> </label>
Selected


HTML
<label class="clara-radio"> <input type="radio" class="clara-radio__input" name="group" checked> <span class="clara-radio__label">Option A</span> </label>
Disabled


HTML
<label class="clara-radio clara-radio--disabled"> <input type="radio" class="clara-radio__input" name="group" disabled> <span class="clara-radio__label">Option A</span> </label>

Option Tile

Larger clickable tiles for prominent option selection. Use for important decisions where visual prominence helps.

States

Unselected
Standard Plan $29/month
HTML
<div class="clara-option-tile" tabindex="0"> <span class="clara-option-tile__title">Standard Plan</span> <span class="clara-option-tile__subtitle">$29/month</span> </div>
Selected
Standard Plan $29/month
HTML
<div class="clara-option-tile clara-option-tile--selected" tabindex="0"> <span class="clara-option-tile__title">Standard Plan</span> <span class="clara-option-tile__subtitle">$29/month</span> </div>
