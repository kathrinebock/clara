# clara
Clara — OK's design system. Design tokens and Web Components built from Figma.

## Setup
1. Clone the repository.
2. Install dependencies (if using npm/yarn/pnpm):
   - `npm install`
   - `yarn install`
   - `pnpm install`
3. Generate or update tokens from the Figma source.
4. Build components and documentation.
5. Review the design system in the browser or Storybook (if configured).

## Structure
- `tokens/` — design tokens exported from Figma.
- `components/` — Web Components and UI building blocks.
- `.github/` — GitHub configuration, workflows, and issue templates.
